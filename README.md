# Милана в отрыве

Браузерная игра про 30 дней свободы. Милане 20 лет, у неё сумка через плечо и 5 000 ₽ на карте. Она катается по городам, гуляет, ходит по барам, поёт и дерётся.

## Как играть

- **Гулять.** На прогулке случаются события: компании, гопники, споры на деньги. В каждом городе есть свои.
- **В бар.** Даёт кайф, но копит градус. После 4 рюмок возможен провал в памяти.
- **Петь.** Мини-игра: нажимать, когда линия попадает в зелёную зону. В караоке растут подписчики, на улице прохожие кидают деньги.
- **Нарваться.** Пошаговая драка: удар, блок или уклон.
- **Подработка, шаурма, сторис.** Деньги, здоровье и подписчики.
- **Уехать.** Самолёт, плацкарт или автостоп по 8 городам.
- **Спать.** Хостел, вписка или вокзал. Если перебрать, утром будет похмелье.

В конце тура Милана получает титул по итогам игры. Прогресс сохраняется в браузере.

## Запуск

Игра состоит из одного файла `index.html`. Его можно просто открыть в браузере, сервер не нужен.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `milana-game`.
2. Загрузите в него файлы `index.html` и `README.md`: кнопка **Add file → Upload files**.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через минуту-две игра откроется по адресу `https://<ваш-логин>.github.io/milana-game/`.
