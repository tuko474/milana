# Милана в отрыве

Браузерная игра про 30 дней свободы. Милане 20 лет, у неё сумка через плечо и 5 000 ₽ на карте. Она катается по городам, гуляет, ходит по барам, поёт и дерётся.

## Как играть

- **Гулять.** На прогулке случаются события: компании, гопники, споры на деньги. В каждом городе есть свои.
- **В бар.** Даёт кайф, но копит градус. После 4 рюмок возможен провал в памяти.
- **Петь.** Мини-игра: нажимать, когда линия попадает в зелёную зону. В караоке растут подписчики, на улице прохожие кидают деньги.
- **Нарваться.** Пошаговая драка: удар, блок или уклон.
- **Подработка, шаурма, сторис.** Деньги, здоровье и подписчики.
- **Уехать.** Самолёт, плацкарт или автостоп по 8 городам.
- **Спать.** Хостел, вписка или вокзал. Если перебрать, утром будет похмелье.

- **Задание дня.** Каждое утро новое задание: погулять, выиграть драку, спеть на 7+ и т. д. За выполнение дают деньги и подписчиков.
- **Ачивки.** 13 достижений, список открывается кнопкой «Ачивки».
- **Звук и голос.** Звуки драк, караоке, бара и поездок. Голос зачитывает события из ленты, если в браузере есть русский голос. Оба можно выключить кнопками внизу.

В конце тура Милана получает титул по итогам игры. Прогресс сохраняется в браузере.

## Запуск

Игра состоит из одного файла `index.html`. Его можно просто открыть в браузере, сервер не нужен.

## Мини-приложение в Telegram

Бот игры: [@MiloNyashBot](https://t.me/MiloNyashBot). Играть: https://t.me/MiloNyashBot/play

Игра уже умеет работать внутри Telegram: разворачивается на весь экран, вибрирует на ударах и наградах, хранит прогресс в облаке Telegram и делится результатом в чатах.

1. Опубликуйте игру на GitHub Pages (см. ниже). Нужен адрес вида `https://<логин>.github.io/milana-game/`, Telegram требует HTTPS.
2. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и логин бота (должен кончаться на `bot`).
3. Кнопка запуска в чате с ботом: `/mybots` → ваш бот → **Bot Settings → Configure Mini App → Enable Mini App** → вставьте адрес игры. (В старых версиях: **Menu Button** → адрес и подпись «Играть».)
4. Ссылка на игру для друзей: `/newapp` → выберите бота → название, описание, картинка 640×360 → адрес игры → короткое имя, например `play`. Получится `https://t.me/<бот>/play`.
5. Ссылка на бота уже вписана в `index.html` в строку `const TG_LINK`. Там стоит короткая ссылка `https://t.me/MiloNyashBot/play`. Тогда «Поделиться результатом» будет вести прямо в игру.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `milana-game`.
2. Загрузите в него файлы `index.html`, `README.md` и папку `photos`: кнопка **Add file → Upload files**.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через минуту-две игра откроется по адресу `https://<ваш-логин>.github.io/milana-game/`.
